# ISMAC Logistique & Décharges

## Pour lancer l'application sur votre ordinateur :
- Sur Mac / Linux : Double-cliquez sur lancer_application.sh (ou lancez ./lancer_application.sh dans le Terminal)
- Sur Windows : Double-cliquez sur lancer_application.bat

L'application s'ouvrira automatiquement dans votre navigateur à l'adresse : http://localhost:8080
